# Resume builder — Bidder

Built Chrome extension. Download this repository, unzip it, then in Chrome open `chrome://extensions`, turn on Developer mode, and choose **Load unpacked** on this folder (the one that contains this file and `manifest.json`).

Sign in with the bidder ID from the admin site. Building a resume sends the job to whichever computer is running the ChatGPT extension.

The `dice` folder is the Dice extension. Load that folder unpacked in the Chrome profile that is signed in to Dice.
